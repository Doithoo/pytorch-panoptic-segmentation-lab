## Status: complete

Kaggle version 2 ran the repository from a fixed source revision on a Tesla T4. It generated 256 synthetic images, prepared the manifests, trained for 20 epochs, reloaded `best.pt`, evaluated the test split, and exported the run files listed below.

The data is generated by the repository, so these numbers describe the synthetic task and the implementation's non-crowd mask rules. They are not Cityscapes or COCO results.

The checkpoint is not stored in Git. Download it from Kaggle if you need to inspect the tensors:

```bash
kaggle kernels output yashowhoo/pytorch-panoptic-segmentation-lab-gpu \
  --file-pattern 'artifacts/reference-panoptic-unet/best.pt' -p kaggle-output
```
