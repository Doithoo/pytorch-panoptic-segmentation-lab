# Kaggle Reference Run

[简体中文](README.zh-CN.md) | [Kaggle guide](../guides/kaggle.md) | [Reference config](../../configs/reference_kaggle.yaml) | [Kaggle page](https://www.kaggle.com/code/yashowhoo/pytorch-panoptic-segmentation-lab-gpu)

## Status: complete

The deterministic synthetic reference job completed successfully on Kaggle version 2. It validates source checkout, package installation, CUDA execution, data preparation, training, checkpoint reload, test evaluation, and artifact export in one non-interactive task.

This is workflow evidence, not a real-world benchmark. The data is generated by the repository, and the metric implementation follows the project's non-crowd three-mask contract. It must not be presented as Cityscapes or COCO performance.

## Result

| Item | Value |
|---|---:|
| Kaggle version | 2 |
| Hardware | Tesla T4 (`cuda`, 2 devices allocated, one used) |
| Python / PyTorch | 3.12.13 / 2.10.0+cu128 |
| Source revision | `f6fb554066d508f933fe220bf27c39ad2de04d8c` |
| Data | 256 deterministic synthetic images, source 128x128 |
| Split | 205 train / 26 valid / 25 test |
| Model | Panoptic U-Net, base channels 32 |
| Training | 20 epochs, AdamW, cosine schedule, CUDA AMP |
| Best validation PQ | **0.865159** at epoch 20 |
| Test PQ | **0.853881** |
| Test SQ / RQ | 0.973944 / 0.869757 |
| Test PQ thing / stuff | **0.561655 / 0.999993** |
| Test loss | 0.013969 |
| Test TP / FP / FN | 96 / 55 / 4 |
| Training job elapsed | 83.762 seconds |
| Best checkpoint SHA-256 | `30f7905f84fef4db783b6bca7185a1520f2fa5247fc80c23db7ca03c4d32a43a` |

The strong stuff score and lower thing score are expected for this teaching dataset: the baseline learned the broad background regions more easily than object separation. The result is useful for checking the pipeline and error decomposition, not for comparing model quality across datasets.

## Reproduce

The submitted files are [`kaggle/run_kaggle.py`](kaggle/run_kaggle.py) and [`kernel-metadata.json`](kaggle/kernel-metadata.json). The runner pins the source revision above. To submit a new run, update the pinned revision and metadata deliberately, then follow the [Kaggle guide](../guides/kaggle.md).

## Limitations

The run uses no external dataset, no crowd annotations, and no official server evaluator. A real Cityscapes/COCO result still requires a converter, official split, crowd/void adapter, license review, and dataset-specific evaluator comparison.
